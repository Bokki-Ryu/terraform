# N8N Terraform

Install n8n with terraform docker provider

## Prerequisites

- [Install terraform cli](https://developer.hashicorp.com/terraform/install)

## Execute

```bash
terraform init &&
    terraform apply
```

## Reference

- [kreuzwerker/docker](https://registry.terraform.io/providers/kreuzwerker/docker/latest)
